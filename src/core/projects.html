The highlight · 2025 → now

AI agents & MCP servers

Tools for a future where models do more of the work: servers that let an assistant drive professional software, a formatter for the Markdown and LaTeX they write, and a benchmark that checks whether code really scales the way it should.

● Reel
Checks what code really costs★

TempoBench

Benchmark any command in any language over a sweep of input sizes, then let TempoBench fit the growth curve: O(n), O(n log n), O(n²)… with a confidence level and the reason for any doubt. It writes an HTML report and can turn the result into a narrated vertical video.

19,183×Miller–Rabin over trial division at n = 10¹⁶, one of nine algorithm races, each with both classes fitted correctly

Why it matters now: when an agent writes the code, a fitted growth curve is a quick, honest check that it scales.

  • Python
  • CLI
  • Curve fitting
  • Reports
  • Video

Cleans up model output★

marklign

A Markdown formatter written in Rust that takes special care of display LaTeX. It joins orphaned operators into readable expressions and never leaves a line Markdown would misread: a lone = or - inside $$…$$ turns half an equation into a heading in most renderers.

  • Rust
  • Comrak
  • LaTeX
  • Formatter

Directing know-how for models · new★

VideoGenome

An open, renderer-independent specification for video-production expertise. Strong models write and refine blueprints for directing, pacing, sound and design; smaller models pick one and fill in the content, instead of reinventing film-making for every video. Pluggable tools (text-to-speech, ComfyUI, Blender over MCP) make the assets and an FFmpeg renderer assembles the cut.

  • Python
  • Specification
  • Blueprints
  • Rendering

Speech recognition, offline

OpenCaption

A command-line tool in Go, built on whisper.cpp, that turns audio and video into SRT, VTT or JSON captions on your own machine. It runs on the GPU through CUDA, Metal or Vulkan, skips silence with voice-activity detection, and works through whole folders in batch mode.

02

The largest build · C++20 · Qt 6 · OpenGL

A C++ game engine, from scratch

Not a game made in someone else's engine: the renderer, the simulation, the animation, the UI and the tooling are all written from scratch, and they ship together as a real-time strategy game.

Standard of Iron

A single-player real-time strategy game set in an altered Second Punic War. You command formations from above, or take direct control of a commander on the battlefield, while running a settlement economy and assaulting fortified positions. An eight-mission campaign runs from the crossing of the Rhône to Zama.

  • 460klines of C++/QML
  • 2,100+commits
  • 8languages
  • 3platforms

Built with agents: about 925 of its 2,162 commits came from GitHub Copilot coding agents.

Source & downloads ↗ Read the docs
  • RendererA custom multi-tier OpenGL renderer (3.3 core, with a CPU fallback) and its own humanoid, terrain and settlement pipelines.
  • SimulationAn entity-component core, kept apart from presentation: the same systems run the live game, a windowless simulation and the balance tools.
  • ReplayCommand recording and deterministic replay verification, also headless.
  • ArmiesInfantry, archers, cavalry, healers, builders, siege engines and elephants, in authored formations, shield walls and wedges.
  • ToolsA map editor and developer scenarios; Qt and QML only for the interface.
  • ShippingLinux, macOS and Windows builds, saves with versioned migrations, and translations into eight languages.
