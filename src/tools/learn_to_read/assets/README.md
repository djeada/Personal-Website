# Phonics Adventure artwork

Original artwork created with the built-in image-generation tool for this project. PNG originals are retained in the generating workspace; these WebP assets preserve the artwork and transparency while reducing transfer size.

| File | Purpose | Generation prompt |
| --- | --- | --- |
| `finn.webp` | Tap-to-hear guide and friendly companion | A very cute orange fox named Finn, huge warm brown eyes, cream muzzle and belly, rounded paws, oversized head, fluffy tail, mint neckerchief and golden star charm. Sitting and waving, reassuring smile, soft tactile storybook gouache shading, full body, centered with transparent margins. No text, frame or background; true alpha transparency. |
| `adventure-world.webp` | Illustrated play invitation | A delightful preschool storybook landscape: mint-green meadows, winding golden path, soft trees, clouds, smiling sun, daisies and mushrooms. Cozy wooden word-building workshop, magical open picture book and treehouse. Friendly orange fox in a mint neckerchief with a white rabbit on the lower left. Warm sunny gouache, blue sky, buttery yellow, coral and lavender. Open upper-middle sky for separately rendered UI; no labels or interface. |
| `letter-pictures.webp` | Sixteen picture clues, CSS sprite atlas | A square four-by-four grid of separate centered cute gouache illustrations on transparency. Row 1: smiling sun, red apple, baby tiger, pink pig. Row 2: ladybird insect, butterfly net, sleepy crescent moon, puppy. Row 3: baby goat, purple octopus, ginger cat, diamond kite. Row 4: egg in eggcup, umbrella, white rabbit, green hat. Clear recognizable silhouettes, equal cells with safe margins, no visible grid, labels or lettering. |
| `word-pictures.webp` | Sixteen action and object clues, CSS sprite atlas | A square four-by-four grid of separate centered preschool storybook gouache clues on transparency. Row 1: fox sitting on a chair, woven mat, water tap, cooking pan. Row 2: drawing pin, tin can, sleeping fox, treasure map. Row 3: fox patting rabbit, fox sipping a drink, friendly ant, grey mouse. Row 4: grandmother, mother, father, table lamp. Equal padded cells, rounded forms and expressive characters; no text, labels, frames or grid lines. |

The atlas order is part of the interface contract in `app.js`. Images remain decorative to assistive technology because every interactive clue has its own localized accessible name. Reduced-motion preferences disable character motion. Speech starts after an explicit interaction and uses the device's installed reading voices; audio can be muted.
