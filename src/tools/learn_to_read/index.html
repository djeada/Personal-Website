For grown-ups

How it works

Children learn a few letter sounds at a time in a fixed phonics order, then blend those sounds into real words and read short stories built from them. Each round mixes in earlier sounds, so practice keeps coming back.

Every word, sound and instruction is a recorded clip, so it works the same on every device. Sit together for the first levels and say the sounds aloud with your child.

Sounds so far

Green sounds are secure. Orange sounds need more practice and come back more often.
